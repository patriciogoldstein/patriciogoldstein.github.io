# patriciogoldstein.github.io

Personal academic website of Patricio Goldstein, PhD Candidate in Economics at
Columbia University. Live at <https://patriciogoldstein.github.io>.

Built with [Jekyll](https://jekyllrb.com/) on a trimmed-down version of the
[al-folio](https://github.com/alshedivat/al-folio) theme (MIT licensed), and
deployed to GitHub Pages via `.github/workflows/deploy.yml`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
